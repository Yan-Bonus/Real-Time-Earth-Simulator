# 场景与联网交互

EarthScene 使用标准 OrbitControls 直接控制相机，阻尼仅平滑手势，不等待网络。最近 1.5R、初始 3.8R、最远 8R。

RegionalImagery 首先将在线第 3 级瓦片拼成全球纹理，EOX 4096×2048、NASA 5120×2560，全球基础层仅一个绘制对象。完成后可任意旋转。

高清加载根据真实相机和显示像素选择可见瓦片，移动期间节流更新队列，停止后补齐；始终可用全球层或已缓存父层覆盖缺失细节，子层不透明替换。各层使用同一个实时地球姿态。

会话内复用影像，保留在途下载，更新排队目标；空闲 500ms 后预取相邻瓦片，4 个并发、15 秒超时、单轮两次尝试、失败 10 秒后再尝试或手动重试。源切换保留旧全球层，直到新源全球层就绪。所有地表仅来自网络，退出清理，无磁盘影像缓存。

纹理估算上限 512MiB（不包括解码、几何和驱动内存）；按来源瓦片尺寸与全球层占用计算可见叶预算，最多 1536。几何按 1.2° 角跨度细分，避免小瓦片固定 32×32 网格；父层只在子层未就绪时用于覆盖。画质状态仅在当前叶节点完成且达到密度阈值时标为 ready。

最高画质密度阈值保持 0.9；源本身的纹理质量和海底填充不由采样阈值保证。旋转中允许短暂较低细节，以用户最新确认覆盖旧相机事务方案。不实现城市、太阳、昼夜或云层。

## 内置全球资源与永久影像库（2026-10-01）

全球默认 EOX 2024 第3级128瓦片已预拼为4096×2048无损PNG（6,445,173字节），随安装包交付并在构建时检查SHA-256与元数据。首次启动不需要基础影像网络请求。区域高清按需下载，长期保存原始压缩瓦片，默认Windows路径D:\RealTimeEarthSimulatorData\imagery；不设容量上限，不自动删除。可用磁盘空间不足256MiB安全余量时暂停新增保存并提示，仍可浏览已有影像与联网资源。

保留即时相机与1.5R最近距离，增加必要父层、当前视野优先、受限4/6/8吞吐量探测和故障退避。纹理上传按每帧最多2块与3ms开始预算分批；单次上传自身可能超预算，须以实测帧间隔评估。影像来源、版本和地理矩阵分别保存，失败写入不能当成完整资源。
